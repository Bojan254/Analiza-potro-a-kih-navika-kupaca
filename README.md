# Analiza potrošačkih navika kupaca

Analiza baze podataka premium prehrambenog maloprodajnog lanca s ciljem 
identifikacije obrazaca u potrošačkim navikama kupaca.
Projekat realizovan u okviru Škole analitike i vještačke inteligencije.

## Tehnologije
- Python (Pandas, NumPy) — Google Colab
- SQL — SQLiteOnline
- Power BI

## Sadržaj projekta

### Python analiza
Čišćenje i priprema baze podataka, uključujući:
- Kategorizacija kupaca po starosti, prihodima i kupovnim navikama
- Analiza ukupne potrošnje po kupcu i kategoriji proizvoda
- Analiza kupovine na popust

### SQL upiti
- Analiza potrošnje u odnosu na broj djece u domaćinstvu
- Analiza potrošnje po kategorijama prihoda
- Analiza potrošnje po starosnim grupama i kategorijama proizvoda
- Analiza profila kupaca koji kupuju na popust

## Baza podataka
Marketing Campaign dataset — sadrži podatke o 2.000+ kupaca 
uključujući demografske podatke, prihode i potrošačke navike.
